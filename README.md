# Situation Intelligence — ThreadAtlas

This repository is being initialized with **ThreadAtlas**, a clean-room discussion-to-dataset intelligence product tracked by [RE-374](https://github.com/rrahul0904/situation-intelligence/issues/1).

ThreadAtlas turns conversational source material into a typed, reviewable collection with provenance, dedupe/conflict handling, revision history, grouping, and visualizations.

## Clean-room boundary

The product concept was researched from public Reddit and wiki.bot surfaces only. No proprietary source code, private APIs, hidden prompts, copied visual assets, or branding are used. Public behavior is treated as inspiration; implementation details here are original.

The implementation is developed on feature branches and is not considered production-ready until exact-head tests, build, and hosted runtime behavior are independently verified.
